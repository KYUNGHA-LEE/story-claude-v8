# 동화책 프롬프트 생성기 V8 · 오디오 플립북

`동화책 프롬프트 생성기_V7_에셋/index.html`(2026.11.01)에 5~7단계를 더한 버전 (2026.11.01). V7 폴더는 그대로 두었다.

- **배포 주소**: https://story-claude-v8.vercel.app/
- **저장소**: https://github.com/KYUNGHA-LEE/story-claude-v8 (main에 푸시하면 Vercel 프로젝트 `story-claude-v8`이 자동 배포)
- V7은 그대로: https://story-claude-v7.vercel.app/

## V8에서 더한 것

| 단계 | 하는 일 |
|---|---|
| 5. 그림 올리기 | 쪽마다 그림을 올린다. 여러 장을 끌어다 놓으면 파일 이름의 쪽 번호(숫자가 하나뿐일 때, 예: `img3.png`, `p03.png`)대로, 번호가 없으면 파일 저장 시각 순서대로 1쪽부터 넣는다. 카드에 하나씩 끌어다 놓기·바꾸기·빼기·◀▶(앞뒤 쪽과 바꾸기). 그림 비율이 2단계 책 크기와 다르면 잘라서 보여 주고, 좌우(또는 위아래) 위치 막대로 자를 곳을 고른다. 원본 파일은 바뀌지 않음 |
| 6. 음성 올리기 | 같은 방식으로 쪽마다 음성(MP3·WAV·M4A 등)을 올린다. 쪽마다 미리 듣기와 길이, 전체 길이 표시 |
| 5·7단계 · 그림에 원고가 들어 있나요? | 5단계 위쪽과 7단계에서 같은 질문을 한다(둘이 연결, 브라우저에 기억). **아니요**(또는 아직 안 고름) → 왼쪽 그림·오른쪽 원고 펼침면. **네**(캔바 등에서 원고를 그림에 넣음) → 원고를 따로 넣지 않고 그림만, 글자가 잘리지 않게 **자르지 않고 전체**를 보여 줌(5단계 자를 위치 막대 숨김). 사용자 요청: AI가 원고를 그림 위에 얹으면 그림을 너무 많이 가리므로, 그림에 글을 넣는 일은 캔바에서 한다 |
| 7. 오디오 플립북 | 책장을 넘기면 0.45초 뒤 그 쪽 음성을 처음부터 읽는다. 소리 듣기/멈춤, 다시 듣기, 처음으로, 자동 넘김(다 읽고 1.5초 뒤 다음 쪽), 전체 화면, 키보드 ← → 와 스페이스. ① **펼침면**: 표지 → (왼쪽 그림 · 오른쪽 원고) → 뒤표지. 좁은 화면은 한 쪽씩(그림 → 글), 같은 쪽의 그림에서 글로 넘어갈 때 소리가 끊기지 않음 ② **그림만**: 표지 → 그림 쪽들 → 뒤표지. 넓은 화면은 두 쪽이 펼쳐지고 왼쪽 → 오른쪽 차례로 읽음(쪽 사이 0.5초), 좁은 화면은 한 쪽씩. 쪽 수가 홀수면 뒤표지 앞에 빈 쪽을 넣음 |
| 7단계 · 플립북 파일로 받기 | 완성된 플립북을 **HTML 파일 하나**로 받는다. 그림(긴 변 최대 1600px JPG, 품질 0.86 — 펼침면은 책 비율로 잘라서, 그림만은 자르지 않고 책 비율 종이 위에 전체)·음성(원본 그대로)·page-flip 라이브러리 원문·보기 코드(`flipbookViewer`)가 모두 들어 있어 인터넷 없이 더블클릭으로 열린다. 그림·음성이 빠진 쪽이 있으면 받기 전에 알려 준다 |

- 책장 넘김: [page-flip 2.0.7](https://github.com/Nodlik/StPageFlip) (MIT, jsDelivr CDN) — story-flipbook이 쓰는 react-pageflip의 바탕 라이브러리
- 그림·음성 보관: 브라우저 IndexedDB `storybookAudioFlipbook_v8` (서버로 보내지 않음, API 키 필요 없음). JSON 저장에는 들어가지 않으므로 다른 컴퓨터에서는 다시 올려야 한다
- 1~4단계는 V7과 같다. 단, 3단계 표의 머리글 `| 페이지 | 원고 |` 이 원고 카드(와 1쪽 원고)로 읽히던 문제를 고쳤다 (V7에는 그대로 있음)

## 시험한 것 (2026-11-01, 이 PC의 Claude 앱 내장 브라우저 · Chromium 152, 로컬 서버)

- 「겁많은 토끼의 용감한 도전」 JSON + 그림 6장(순서를 섞어 끌어다 놓기) + 가로 그림 1장(2쪽 교체, 좌우 위치 25%) + 음성 6개(1p~6p, 순서 섞음) → 모두 쪽 번호대로 들어감
- 새로고침 뒤에도 그림·음성·자를 위치 유지
- 넓은 화면: 표지 → [▶ 소리 듣기] → 1쪽 펼침면에서 1쪽 음성 재생, [다음 ▶] → 2쪽 음성 처음부터, 자동 넘김으로 2쪽 → 3쪽 넘어가며 3쪽 음성 재생
- 휴대폰 크기(375px): 한 쪽씩 보기로 바뀌고 쪽 위치 유지, 1쪽 그림 → 1쪽 글로 넘겨도 음성이 이어짐, 멈춘 상태에서 화면 크기가 바뀌어도 저절로 재생되지 않음
- ◀▶ 바꾸기·빼기 동작, 콘솔 오류 없음
- 플립북 파일로 받기: 토끼 책 6쪽(PNG 원본 약 19MB) → 4.77MB HTML, 그림 6·음성 6 포함, 바깥 주소는 글꼴(Google Fonts) 하나뿐(없으면 기본 글꼴). 받은 파일에서 표지 → [▶ 소리 듣기] → 1쪽 재생, [다음 ▶] → 2쪽 재생, 멈춤 확인 (로컬 서버로 열어 시험)
- 사용자가 받은 파일(펼침면)을 자기 PC에서 열어 "잘 돼" 확인 (2026-11-01)
- 그림에 원고가 들어 있음(네): 5단계 질문 표시·저장·7단계와 연결, 가로 그림이 잘리지 않고 전체 표시·자를 위치 막대 숨김, 플립북 8장(표지·그림 6·뒤표지, 글 쪽 없음), 1–2쪽 펼침에서 1쪽 → 2쪽 차례로 읽고 자동 넘김으로 3–4쪽, 휴대폰 크기에서 한 쪽씩, 쪽 수 5일 때 빈 쪽 추가, 받은 파일에서 그림 전체(가로 그림 1600×1600 종이 위)·1쪽 재생. '아니요'로 바꾸면 다시 글 쪽 6장 포함 14장
- **안 해 본 것**: 실제 크롬·엣지·사파리(아이폰·아이패드), 실제 파일 고르기 창(시험은 끌어다 놓기 이벤트로 함), 큰 그림 수십 장, 전체 화면 버튼, 받은 파일을 카톡·아이폰에서 연 경우, 실제 캔바에서 원고를 넣은 그림

## 고칠 때 주의

- 앱 전체가 `<script>` 안에 있으므로, 받는 파일을 만드는 문자열에 닫는 script 태그를 그대로 쓰면 앱이 깨진다. `<\/script>` 로 쓴다 (`buildExportHtml`)
- 책 화면은 `flipbookViewer` 하나를 앱 7단계와 받은 파일이 같이 쓴다(받은 파일에는 `toString()`으로 옮겨짐). 그래서 이 함수 안에서는 앱의 변수·함수를 쓰면 안 된다. 책 화면 스타일은 `VIEWER_CSS`(앱은 실행할 때 `<style>`로 넣고, 받은 파일에도 그대로 들어감)

# 동화책 프롬프트 생성기 V7 · 에셋

`동화책 프롬프트 생성기_Claude/index.html`(2026.09.17)을 바탕으로 2026.11.01에 새로 만든 버전. 원본은 그대로 두고 이 폴더에만 변경을 담았다.

- **배포 주소**: https://story-claude-v7.vercel.app/
- **저장소**: https://github.com/KYUNGHA-LEE/story-claude-v7 (main에 푸시하면 Vercel 프로젝트 `story-claude-v7`이 자동 배포)

## 바뀐 점

| 항목 | 이전(_Claude) | V7 |
|---|---|---|
| 모델 | gemini-2.5-flash | **gemini-3.8-flash** 기본. 과부하·한도 초과·시간 초과 시 자동 전환. 품질 우선: 3.8 → 3.6 → 3.5-flash-lite → 2.5 → 2.5-flash-lite / 무료 키 우선: 3.5-flash-lite → 2.5-flash-lite → 2.5 → 3.6 → 3.8. 키 입력칸 아래에서 선택·고정 가능 |
| 응답 | 한 번에 수신 | **스트리밍**으로 결과칸에 실시간 표시, 버튼에 경과 시간·모델·글자 수. 45초 무응답/60초 정지 시 다음 모델 |
| 1단계 | AI가 줄거리 생성 | **사용자가 직접 작성** (AI 초안은 선택 버튼) + **책 분량(페이지 수·페이지당 문장 수)을 여기서 결정** — 2단계 장면 개수와 3단계 원고 분량의 기준 |
| 2단계 | 캐릭터만 (정면 1장) | **에셋 = 캐릭터 · 장면 · 도구** 세 종류. 캐릭터는 반복 등장하는 주요 캐릭터만, **앞·옆·뒤 전신 + 표정(기본 기쁨·슬픔·놀람·화남, 입력칸에서 변경)이 한 장에 담긴 캐릭터 시트**로 생성. 장면은 필요한 배경 전부(개수 제한 없음), 도구는 중요한 소품 |
| 3단계 | 페이지 원고 (분량 입력도 여기) | 분량 입력은 1단계로 이동. 1단계 분량대로 쓰고 에셋 이름을 그대로 쓰도록 요청 |
| 4단계 | 장면 프롬프트에 캐릭터 명세 전체 복사 | **전체 장면 프롬프트 + 사용 에셋을 색으로 표시** (캐릭터 청록 · 장면 주황 · 도구 보라). 참조 이미지를 첨부해 쓰는 흐름이므로 명세 전체 복사는 하지 않고 핵심 식별 특징만 덧붙임 |

## 4단계 복사 버튼이 복사하는 내용

```
(장면 프롬프트 본문)
[참조 이미지 첨부] 캐릭터: 민호, 책벌레 · 장면: 밤의 도서관 열람실 · 도구: 반짝이는 글자책 — 첨부한 참조 이미지 속 캐릭터·장면·도구의 외형, 색, 구조를 그대로 유지할 것
[화풍: ..., 크기: 가로 210mm × 세로 210mm]
```

칩(에셋 이름)을 누르면 그 에셋의 2단계 참조 프롬프트가 복사된다. `(신규)`로 표시된 장면은 2단계 표에 없는 배경이므로 필요하면 2단계 표에 추가한다.

## 표 형식 (직접 고칠 때)

- 2단계: `| 종류 | 에셋 이름 | 설명 | 참조 이미지 프롬프트 |` — 종류는 `캐릭터` / `장면` / `도구`
- 4단계: `| 페이지 | 사용 에셋 | 장면 프롬프트 |` — 사용 에셋은 `캐릭터: 이름1, 이름2 / 장면: 이름 / 도구: 이름`
